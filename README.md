# ☕ ChaiKadai

Tamil street food delivery landing page

## Features

- Mobile-first responsive design
- Authentic Tamil kadai color scheme
- Scroll reveal animations
- Vanilla JavaScript (no frameworks)

## Use of Generative AI
This project was developed with the assistance of AI (Qwen) for code generation and debugging support. All creative direction, design decisions, content, and architectural choices are my own. I used AI as a collaborative tool to accelerate development while maintaining full ownership of the project's vision and implementation.
